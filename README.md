# Worcadian Agent

Generates engaging social media posts and newspaper-style press releases about the [Worcadian](https://whatgamestudios.com/worcadian/) 
word puzzle.

Entire iterations of the design and implementation of the agent are included in the [v1](./v1/), [v2](./v2/), and [v3](./v3/) directories. v3 deploys the agent as a FastAPI service on Vercel, with a scheduled daily email and a simple web UI.
